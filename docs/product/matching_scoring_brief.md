# 美团式匹配评分排行(需求 → 匹配 → 评分 → 榜单)Brief

## 用户与问题
采购方带着需求来平台("我要做智能手表,需要 CNC 结构件,苏州"),要得到美团式体验:
系统匹配好、每家挂综合评分、能看排行榜。现状:评分只有 QCDST(履约单据驱动,样本门槛 15 批),
52 家真实供应商多数无履约数据 → 榜上无分可看,体验断裂。

## 已确认决策(用户拍板)
1. **评分口径 = Y 方案加权综合分**:QCDST 履约 40% + 需求匹配度 30% + 工商实力 15% + 4M1E 现场档案 15%,权重可配
2. **匹配形态两个都要**:① 寻源搜索结果带综合分排序(一期);② 发布需求 → 供应商应答(二期)
3. **榜单**:综合总榜 + 32 类工艺品类榜
4. **无数据供应商**:进榜,但维度置 0 并挂「证据不足/无数据」标记,分数旁带置信标识

## 分项口径(每个分项必须可解释、可展开看构成)
- **QCDST 履约(40%)**:复用现有 qcdst 评级,样本不足按 0 计 + 「证据不足」标记,QCDST 本身口径不动
- **匹配度(30%)**:复用 supply_match 的可解释匹配分(能力覆盖/同城协同/资本门槛);排行榜无需求上下文时,该维度替换为「能力覆盖度」(该供应商挂的工艺能力数)
- **工商实力(15%)**:注册资本(对数分档)+ 参保人数(分档)+ 成立年限(分档)+ 进出口权,各 0–100 加权
- **4M1E 档案(15%)**:字段填写率(录了多少事实)+ 关键事实加分(体系认证/设备台账/双源),未录入 = 0 + 「无巡厂记录」标记

## In / Out of Scope
**In**:四维综合评分服务(权重可配)、置信标记、综合总榜 + 品类榜、寻源搜索结果带综合分徽章、/ranking 页升级(总榜/品类榜切换)、(二期)需求发布与应答
**Out**:评分的人工干预入口、供应商付费排名(美团商业化那套,明确不做)、自动外采新数据、QCDST 口径变更

## 成功标准
1. 输入需求 → 排序结果列表:每家显示综合分 + 四分项(缺失维度标「无数据」)+ 可解释理由
2. 总榜/品类榜可切换;权重调整后榜单生效(权重从配置读)
3. 所有分数可展开看构成(分项 → 子项 → 证据口径),延续项目"分数能追到单据"原则

## 主路径场景
输入需求 → 解析(能力/区域/资本/关键词)→ 候选召回 → 四维评分(缺失置 0+标记)→ 排序展示 → 点开档案。
失败兜底:需求解析无能力命中 → 全库按综合分排序并提示;QCDST 证据不足 → 该维度 0 分+标记,不隐藏供应商。

## 关键约束
- 评分实时计算,不落库(供应商数据变化即评分变化);权重配置走后端常量,后续可开放配置
- 延续数据哲学:缺失标记「无数据」,绝不填充;置信标识必须显眼
- 二期需求/应答需要新存储(挂 srm store 扩展)

## 借鉴调研(≤15 行)
- 美团类比已由用户给出(商家/用户/评分/榜单),对标其"搜索排序 + 商家分 + 榜单"三层;外部开源可比项目弱,不外搜
- 对架构的直接影响:
  1. 新增 scoring 服务(四维合成,纯函数,输入现有各服务输出)
  2. /search 与 /ranking 接入综合分;新增权重配置
  3. 二期新增 demand 实体与应答存储(srm store 扩展)+ 两侧页面
